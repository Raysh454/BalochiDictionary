Source: <https://www.c-salt.org/downloads/mehr-e-nastaliq-font>

Android ships only a Naskh face for Arabic-script text. Urdu poetry is set in
Nastaliq, and this is the same face rekhta.org serves, so the sher renders with
the steep calligraphic slope it is written with. Nastaliq descends sharply
across each line, which is why the verse layout allows far more line height
than a Latin face would need.
