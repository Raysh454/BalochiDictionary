# Third party notices

## Noto Nastaliq Urdu

`android/app/src/main/res/font/noto_nastaliq_urdu.ttf` is **Noto Nastaliq Urdu**
(Regular) from the Google Noto project, used under the SIL Open Font License 1.1.

Source: <https://github.com/googlefonts/noto-fonts>

Android ships a Naskh face for Arabic-script text. Urdu poetry is set in
Nastaliq, so the verse widget bundles this font to render the sher the way it is
actually written. Nastaliq slopes steeply across the line, which is why the
verse layout allows far more line height than a Latin face would need.
